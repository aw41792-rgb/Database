# شلک منځنی ښوونځی – د مدیریت اپلېکېشن

دا د شلک منځني ښوونځي د Android آف‌لاین اپلېکېشن لومړنی بنسټ دی.

- Flutter او پښتو RTL بڼه
- SQLite ځايي ډیټابېس
- د زده‌کوونکو ثبت او لېست
- GitHub Actions د تحلیل، ازموینې او APK جوړولو لپاره

دا لومړنی پړاو دی؛ د ښوونکو، حاضري، ازموینو، اجناسو، مکتوبونو، راپورونو او بیک‌اپ بشپړ ماډیولونه لا نه دي بشپړ شوي.
